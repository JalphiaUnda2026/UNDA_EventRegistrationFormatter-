# Event Registration Formatter

## Project Description
The Event Registration Formatter is a Python
program that collects student information and
event details. It formats names, sections, event
titles, and dates into a clean and readable format.
## Features
- Accepts student first and last names.
- Accepts the student's section.
- Accepts event name and date.
- Removes unnecessary spaces.
- Formats names using title case.
- Converts names and sections into uppercase.
- Displays dates in a readable format.

## Programming Language
Python

## String Methods Used
- strip()
- title()
- upper()

## Date/Time Feature
- datetime

## Versions

### Version 1
Initial version with basic input and output.

### Version 2
Added string formatting methods.

### Version 3
Added date formatting using datetime.

## How to Run
1. Install Python.
2. Open the Python source code.
3. Run the program.
4. Enter the required student and event details.
5. View the registration summary.
